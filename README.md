##  Project Overview
This repository contains our team's implementation and adaptation of an FCN architecture to perform semantic segmentation on the CamVid street-view dataset. We are focusing on structuring the network layers for urban scene mapping and exploring solutions for class imbalances (e.g., sky vs. signs) through customized loss functions.
